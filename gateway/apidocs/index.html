cerebro API

Four HTTP services behind one address. This page documents them; everything here runs against this instance.

How to use it

  1. Base URL. Every service lives under /api/<service>: /api/memory, /api/docs, /api/flows, /api/auth. The old prefixes without /api (/memory, …) still work as aliases.
  2. Authenticate with Authorization: Bearer <token> on every call. Get a token in the portal (API tokens), with cerebro token create, or sign in below to get a 12-hour session token.
  3. Try it. Paste the token here, pick a service and use Try it out on any endpoint.
Or sign in with a username and password 
curl -H "Authorization: Bearer $CEREBRO_TOKEN" "$HOST/api/memory/contexts"

MCP

The same tools the CLI and the stdio server expose are available over HTTP at /mcp (streamable HTTP, stateless). The assistant can do exactly what the token behind the connection allows.

Sign in through the connection (claude.ai, ChatGPT, Cursor, any MCP client that cannot set headers): add a custom connector with just the URL $HOST/mcp. The client opens the cerebro sign-in page and, once you confirm, registers the token by itself.

Token in a header (Claude Code, scripts): send Authorization: Bearer <token> on every request. A request with neither is rejected with 401.

claude mcp add --transport http cerebro "$HOST/mcp" --header "Authorization: Bearer $CEREBRO_TOKEN"
